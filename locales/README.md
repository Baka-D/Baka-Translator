# 界面文案

中文文案编辑 `zh-cn.json`，英文文案编辑 `en.json`，韩文文案编辑 `ko.json`。三份文件使用相同的语义键。动态内容用 `$1` 至 `$9` 表示，每个键在各语言中都需保留相同的占位符。

修改后运行 `npm run localize`，生成 Chromium 使用的 `_locales/{zh_CN,en,ko}/messages.json`。运行 `npm run localize:check` 可检查词条、占位符和生成结果。打包时也会自动生成。

界面语言默认随浏览器的显示语言自动选择，未提供对应翻译时回退到中文。用户可以在扩展设置中手动选择中文、英文或韩文。翻译输出语言单独设置。
