Baka Translator 개인정보 처리방침

이 방침은 2026년 11월 18일부터 시행되며 확장 프로그램 버전 1.3.0에 적용됩니다.

적용 범위

Baka Translator는 사용자가 선택한 모델 서비스를 이용해 웹페이지, 선택한 텍스트, 이미지 속 글자를 번역하고 번역문을 다듬으며 라이트 노벨 읽기를 돕습니다. 이 방침은 확장 프로그램이 어떤 정보를 처리하는지, 누가 그 정보를 받는지, 어디에 보관하는지, 사용자가 어떻게 관리할 수 있는지를 설명합니다.

확장 프로그램은 작업에 필요한 내용을 사용자가 선택한 모델 서비스로 직접 보냅니다. 개발자는 콘텐츠를 중계하는 서버를 운영하지 않으며 확장 프로그램의 사용 분석 데이터나 광고 추적 데이터를 받지 않습니다.

처리하는 정보와 이용 목적

확장 프로그램은 사용자가 입력한 API 키와 설정한 서비스 제공업체, 모델, 사용자 지정 API 주소, 추론 강도 및 프롬프트를 사용해 서비스에 연결하고 요청을 처리합니다. 번역 대상 언어는 모델이 번역문을 작성할 언어를 정합니다. 화면 표시 언어, 원문과 번역문을 함께 표시하는 설정, 사이트별 설정은 기기에 저장됩니다. 표시 언어는 브라우저 언어를 따르거나 중국어 간체, 영어, 한국어 중에서 직접 선택할 수 있습니다. 화면에 쓰이는 문구는 확장 프로그램에 포함되어 있어 표시 언어를 바꿀 때 모델 서비스에 요청을 보내지 않습니다.

번역, 번역문 다듬기 및 라이트 노벨 기능은 본문, 선택한 텍스트, 초벌 번역, 문맥 파악에 필요한 앞부분이나 이전 회차의 내용, 작품 제목 및 관련 용어를 사용할 수 있습니다. 이미지 번역에는 현재 탭에서 보이는 영역의 스크린샷, 잘라낸 이미지, 인식한 원문과 번역문을 사용합니다.

확장 프로그램은 현재 사이트의 도메인을 기준으로 사이트별 설정을 저장합니다. 소설 회차와 캐시를 연결하기 위해 소설 사이트, 작품 및 회차 식별자, 회차 주소와 제목, 원문과 번역문 캐시, 처리 시각 및 관련 설정도 기기에 기록합니다. 전체 웹 탐색 활동을 아우르는 방문 기록은 만들지 않습니다.

사용자가 이용 현황을 확인할 수 있도록 API 요청 횟수, 토큰 사용량, 캐시 사용량, 예상 비용 및 갱신 시각을 기기에서 집계합니다. 클릭, 키 입력, 마우스 위치 또는 스크롤 경로는 기록하지 않습니다.

웹메일, 채팅 또는 다른 통신 내용을 번역할 때 그 안의 텍스트나 이미지가 모델 서비스에 전송될 수 있습니다. 페이지 전체 번역은 같은 페이지에 새로 도착한 메시지도 처리할 수 있으며, 그 범위는 다음 절에서 설명합니다. 확장 프로그램은 이메일 API에 연결하거나 백그라운드에서 메일이나 메시지를 동기화하지 않습니다. 번역할 내용에 개인정보나 민감한 정보가 포함될 수 있지만, 확장 프로그램은 이름, 건강, 결제 또는 신용 상태 등의 항목별로 별도 기록을 만들지 않습니다.

콘텐츠를 처리하는 시점

일반 웹페이지에서는 도구 모음, 단축키, 마우스 오른쪽 버튼 메뉴 또는 확장 프로그램 화면에서 번역을 시작할 수 있습니다. 현재 탭에서 보이는 영역은 이미지 번역을 사용할 때만 캡처합니다.

페이지 전체 번역을 시작하면 스크롤할 때 불러온 문단이나 새로 도착한 메시지처럼 같은 페이지에 새로 나타난 텍스트도 선택한 모델로 자동 전송될 수 있습니다. 페이지를 원래대로 복원하거나 현재 페이지를 벗어나거나 추가 번역 한도(페이지당 60,000자 또는 텍스트 노드 1,200개)에 이르면 이 처리가 중단됩니다. 같은 페이지 안에서 기존 앵커로 이동하면 여전히 같은 페이지로 간주합니다. 페이지 안에 삽입된 프레임의 경우 번역을 시작할 때 이미 존재하고 확장 프로그램이 접근할 수 있는 문서만 이 범위에 포함됩니다. 이후에 불러온 프레임 문서는 자동으로 번역하지 않습니다.

‘소설가가 되자(小説家になろう)’와 ‘카쿠요무(カクヨム)’에서 지원하는 회차 페이지를 열면 확장 프로그램에 포함된 스크립트가 자동으로 실행되어 회차를 식별합니다. 사용자가 회차 전체 번역을 시작하면 작품과 회차 정보를 기록하며, 문맥을 불러오고 용어를 추출하거나 현재 회차를 캐시에 저장할 수 있습니다. 해당 사이트에서 ‘다음 화 미리 번역’을 켜면 원래 사이트에서 다음 회차를 읽어 모델에 미리 번역을 요청하고, 사용자가 그 회차를 열었을 때 번역을 적용하거나 이어서 진행할 수 있습니다. 이미 시작한 백그라운드 미리 번역 작업은 페이지를 떠난 뒤에도 계속될 수 있습니다.

용어집 자동 정리를 켜면 설정한 회차 수에 이르렀을 때 작품 제목과 정리할 항목을 사용자가 지정한 번역 모델 또는 다듬기 모델에 보냅니다. 항목에는 원문, 번역명, 별칭, 분류, 성별 및 메모가 포함될 수 있습니다. 정리 제안을 재검토할 때는 모델이 작품 속 용어의 의미를 판단할 수 있도록 기기에 캐시된 회차에서 발췌한 짧은 원문을 보낼 수도 있습니다.

데이터를 받는 곳

기본으로 제공하는 모델 서비스에는 DeepSeek, OpenAI, Anthropic, xAI 및 Google이 있습니다. 사용자 지정 API를 사용하면 입력한 주소에 따라 데이터를 받는 곳이 결정됩니다. 번역과 다듬기에 서로 다른 제공업체를 선택할 수 있으므로 관련 원문, 초벌 번역, 문맥, 프롬프트 및 용어가 서로 다른 곳으로 전송될 수 있습니다.

모델을 호출하거나 연결을 테스트하거나 모델 목록을 불러올 때는 API가 요구하는 방식에 따라 선택한 제공업체에 인증 정보로 API 키를 보냅니다. 모델 목록을 불러올 때는 방금 입력하고 아직 저장하지 않은 키도 사용할 수 있습니다. 이 요청에는 웹페이지 본문이 포함되지 않습니다. 저장한 키를 번역할 본문이나 프롬프트에 삽입하지 않습니다.

이미지 번역을 실행하면 먼저 기기에서 스크린샷을 찍고 이미지 위치에 맞게 잘라낸 뒤 크기를 조정하고 압축합니다. 비전 모델에 전송되는 픽셀은 잘라낸 영역의 픽셀이며 가장자리에는 인접한 웹페이지 내용이 일부 포함될 수 있습니다. 탭의 전체 스크린샷은 기기에만 머뭅니다.

모델 API로 보내는 요청에는 브라우저 쿠키가 포함되지 않습니다. 원래 소설 사이트에서 인접 회차를 읽을 때는 사용자가 접근할 권한이 있는 콘텐츠를 불러오기 위해 브라우저가 해당 사이트의 기존 로그인 세션 정보를 함께 보낼 수 있습니다. 확장 프로그램은 쿠키 API를 통해 쿠키 값을 읽거나 내보내지 않습니다.

데이터를 받는 곳은 요청 내용과 인증 정보, IP 주소 및 요청 시각 등의 네트워크 정보를 받을 수 있습니다. 로그를 보관하는지, 데이터를 학습이나 사람에 의한 검토에 사용하는지, 어디에서 처리하고 어떻게 삭제하는지는 제공업체의 정책과 사용자의 계정 설정에 따라 달라집니다. 사용자 지정 API를 이용할 때도 실제로 데이터를 받는 곳의 정책을 확인하세요.

기기 내 저장과 보관 기간

API 키, 설정, 모델 목록과 모델별 지원 기능 기록, 용어집, 작품 메타데이터, 회차 캐시 및 사용량 통계는 사용자의 브라우저에 있는 chrome.storage.local에 저장합니다. 확장 프로그램은 chrome.storage.sync로 이 데이터를 동기화하지 않습니다. 확장 프로그램은 API 키를 별도로 암호화하지 않으며, 기기에 저장된 정보는 브라우저와 운영체제의 접근 제어 및 기기 보안에 의존합니다.

작품당 최대 30개 회차를 캐시에 저장하며, 회차 캐시의 유효기간은 30일입니다. 확장 프로그램이 캐시를 읽거나 이후에 캐시에 쓸 때 만료 여부를 확인하므로 실제 정리 시점은 만료일보다 늦을 수 있습니다. 설정, 용어집, 작품 메타데이터에는 일괄 적용되는 자동 만료 기간이 없습니다. 자동 정리로 용어집이 변경되면 마지막 정리를 취소할 수 있도록 정리 직전의 용어집 사본과 정리 기록도 기기에 보관합니다.

전체 스크린샷, 잘라낸 이미지 및 이미지 인식 결과는 현재 작업과 화면 표시를 위해서만 사용하며 영구 저장소에 기록하지 않습니다. 이미지 결과 패널을 닫으면 패널에 보관하던 결과를 비우고 메모리는 브라우저가 해제합니다.

설정 관리와 데이터 삭제

설정에서 저장한 API 키를 교체하거나 삭제하고 모델과 프롬프트를 변경할 수 있습니다. 사이트별 기능이나 용어집 자동 정리를 끄거나 사용량 통계를 초기화할 수도 있습니다. 특정 작품과 대상 언어의 용어집을 비우면 해당 정리 기록도 함께 삭제됩니다. 회차 캐시와 작품 메타데이터는 기기에 남습니다.

브라우저에서 확장 프로그램이 접근할 수 있는 사이트를 관리할 수 있습니다. 확장 프로그램을 제거하면 해당 브라우저에 저장된 확장 프로그램의 로컬 데이터가 삭제됩니다.

기기에서 키를 삭제해도 제공업체가 발급한 키는 폐기되지 않으며, 이미 전송한 요청도 회수할 수 없습니다. 키 폐기, 데이터 보관 설정 변경 또는 제공업체가 이미 받은 데이터의 삭제는 해당 제공업체를 통해 처리해야 합니다.

데이터 전송과 제한적 사용

기본 원격 API 주소는 HTTPS를 사용합니다. 사용자 지정 제공업체 설정에서는 localhost 또는 127.0.0.1의 HTTP 주소도 사용할 수 있습니다. 이러한 로컬 HTTP 연결에는 TLS 전송 암호화가 적용되지 않습니다.

Baka Translator는 Chrome 웹 스토어 사용자 데이터 정책과 그 제한적 사용(Limited Use) 요건을 따릅니다. 확장 프로그램을 통해 얻은 정보는 번역 및 번역과 직접 관련된 기능을 제공하거나 개선하는 데에만 사용합니다. 확장 프로그램은 이 정보를 판매하지 않으며 맞춤형 광고, 광고용 프로파일링, 신용 평가 또는 대출 심사에 사용하지 않습니다. 개발자는 범용 인공지능 모델을 학습시키기 위해 이 정보를 수집하지 않습니다.

선택한 제공업체에 번역에 필요한 데이터를 보내는 것은 모델 기능을 사용하는 과정의 일부입니다. 제3자 서비스가 받은 데이터를 처리하는 방식은 해당 서비스의 정책과 사용자의 계정 설정에 따릅니다.
