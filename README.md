<h1 align="center">Baka Translator</h1>

<p align="center">网页翻译 · 划词翻译 · 图片翻译 · 轻小说翻译</p>

> 免费送的 API 额度不知道用在哪里？来翻译自己喜欢的轻小说试试吧！

适用于 **Google Chrome、Brave、Microsoft Edge 桌面版等 Chromium 内核浏览器**。使用你自己的模型服务翻译网页，
支持 DeepSeek、OpenAI、Claude、Grok、Gemini，也可以添加自定义接口。

## 能做什么

- **整页与划词翻译**：保留网页排版，可显示双语对照，随时还原原文。
- **图片翻译**：识别并翻译当前画面里的图片文字，结果显示在面板中（实验性功能）。
- **译文润色**：让初译更自然，翻译和润色可以使用不同模型。
- **按网站选择风格**：常规、学术、轻小说，各网站可以单独设置。
- **轻小说预翻译**：提前准备下一章，并逐步积累术语库，让角色名等译名更一致。
- **用量统计**：查看使用量和预估费用。

## 安装

### Chrome Web Store（推荐）

1. 打开 [Baka Translator 商店页面](https://chromewebstore.google.com/detail/baka-translator/jfifpihikfhcmdgjfjmobgjkajdbeclh)，点击安装按钮并确认添加扩展。
2. 在浏览器右上角的扩展菜单中，将 Baka Translator 固定到工具栏，方便随时使用。

### 手动安装

1. 从 [Releases](https://github.com/Baka-D/Baka-Translator/releases) 下载 zip，解压到一个固定文件夹；已有本项目文件夹也可直接使用。
2. 在地址栏打开 `chrome://extensions`（Brave 为 `brave://extensions`，Edge 为 `edge://extensions`），开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 将 Baka Translator 固定到工具栏，方便随时使用。

手动安装版升级时，用新版本覆盖原文件夹，再在扩展管理页点击「重新加载」。解压到新文件夹会被当作另一个扩展，看不到原有的 API Key 和术语库。

## 首次使用：配置模型

请先在你要使用的模型服务商处准备 **API Key（调用模型的密钥）**，并确认账户有可用的 API 额度。

1. 点击工具栏中的 Baka Translator 图标，再点击弹窗底部的「设置」。
2. 在「常规 → 服务商」点击你要使用的服务商，填入密钥，点击「保存 API Key」。
3. 切换到「高级 → 模型行为」，在「翻译模型」下先选择**同一个服务商**，再选择模型；修改后会自动保存。
4. 回到「常规」，选中该服务商，点击「测试连接」，确认提示成功。
5. 打开要翻译的普通网页，点击扩展图标，选择「目标语言」，再点「翻译此页面」。

润色模型初次使用可保持「与翻译模型相同」。如果另选其他服务商，也要为它单独保存 API Key。

**找不到想用的模型？** 在「常规 → 服务商」点击「获取模型」，或在「添加模型名称」中输入服务商提供的完整模型名称并点击「添加」，再到「高级 → 模型行为」选用它。「获取模型」只读取模型列表，不能代替「测试连接」。

**使用自定义接口？** 在「常规 → 服务商」点击「＋ 添加服务商」，填写名称、接口地址（base URL）和模型名称，点击「保存服务商」，再保存 API Key，并按上面的步骤选择模型、测试连接。

## 常用操作

| 想做什么 | 如何操作 |
| --- | --- |
| 翻译整页 | 点击扩展图标 →「翻译此页面」，译文会逐步显示在网页中。 |
| 停止或还原 | 翻译中点击「停止并还原」；完成后点击「还原原始页面」。 |
| 只翻译一段文字 | 先用鼠标选中文字，再右键 →「Baka Translator → 翻译选中文本」，译文会显示在选区附近的气泡中。也可点击弹窗中的「翻译选中文本」。 |
| 翻译图片文字 | 先滚动到要翻译的图片，再点击弹窗中的「翻译画面图片」。结果显示在页面左下角的面板中，不会覆盖原图；需要支持图片的翻译模型。 |
| 对照原文 | 打开弹窗中的「保留原文」，译文下方会保留原文。 |
| 调整翻译风格 | 在弹窗中选择「本站预设」（常规、学术或轻小说）；需要进一步调整文风时，可开启「本站润色」。 |

弹窗中的「目标语言」「保留原文」会保存为新的默认值；「本站预设」「本站润色」只对当前网站生效。
页面已翻译时，修改目标语言或「保留原文」后，点击「按新设置重新翻译」；修改预设或润色开关后，先还原再翻译即可应用。

### 快捷键

| 操作 | 默认快捷键 |
| --- | --- |
| 翻译 / 还原页面 | `Alt+Shift+Y` |
| 翻译选中文字 | `Alt+Shift+S` |
| 翻译可见图片 | `Alt+Shift+U` |

快捷键冲突时，可在浏览器扩展管理页的「键盘快捷键」中调整。

## 用它读轻小说

支持 [小説家になろう](https://ncode.syosetu.com/) 和 [カクヨム](https://kakuyomu.jp/)。

1. 打开小说的**章节正文页**（不是作品目录页），点击扩展图标。
2. 将「本站预设」选为「轻小说」，开启「预翻译下一章」；需要润色时，同时开启「本站润色」。
3. 点击「翻译此页面」。当前章翻译完成后，扩展会在后台准备下一章，可在弹窗中查看进度。
4. 等待提示下一章准备好后，再进入下一章，译文会自动显示。若提前翻页，也可以打开弹窗查看接续进度。

同一作品累计翻译完 3 个章节后会自动建立术语库。想修改角色译名，可到「设置 → 高级 → 术语库」编辑并保存，对后续翻译生效。

## 常见问题

- **保存了 Key，仍提示未配置？** 到「高级 → 模型行为」检查翻译模型的服务商，确认与保存 Key 的服务商一致；使用其他服务商润色时，也要配置它的 Key。
- **测试连接失败或翻译报错？** 检查密钥、API 余额和模型访问权限。自定义接口还需核对 base URL 和模型名称；仅能获取模型列表，不代表所选模型一定能调用。
- **按钮灰色或提示无法在此页面使用？** 浏览器设置页、受保护的扩展商店和内置 PDF 阅读器无法翻译，请换到普通网页。翻译本地文件需在扩展详情中开启「允许访问文件网址」。
- **图片按钮不可用或没有结果？** 检查翻译模型是否支持图片，并确认图片已出现在当前可见画面中；滚动后需再次触发图片翻译。
- **翻译或润色太慢？** 可在「高级 → 模型行为」降低模型的思考强度，或先关闭「本站润色」和「预翻译下一章」，只翻译当前页。

## 使用前了解

- **扩展本身免费，需自行准备 API Key。** 模型调用可能收费，润色和预翻译也会消耗额度；预估费用仅供参考，以服务商账单为准。
- **内容只发送给你选择的模型服务。** API Key、设置和翻译缓存保存在本机浏览器；扩展没有自建中转服务器或使用追踪。
