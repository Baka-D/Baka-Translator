Baka Translator 隐私政策

生效日期为 2026 年 11 月 18 日，适用于扩展 1.3.0 版。

政策范围

Baka Translator 使用您选择的模型服务翻译网页、选中文字和图片，润色译文，并辅助阅读轻小说。本政策说明扩展处理哪些信息、谁会收到这些信息、信息保留在哪里，以及您可以如何管理它们。

扩展将处理任务所需的内容直接发给您选择的模型服务。开发者不运营内容中转服务器，也不接收扩展的使用分析或广告追踪数据。

处理的信息与用途

扩展使用您填写的 API 密钥、服务商、模型、自定义接口地址、推理强度和提示词来连接服务并执行请求。翻译目标语言决定模型的输出。界面语言、双语显示和各网站的设置保存在本机。界面语言可以跟随浏览器或手动选择简体中文、英文、韩文。界面词条随扩展提供，切换语言无需请求模型服务。

翻译、润色和轻小说功能可能使用正文、选中文字、初译、必要的前文或前章上下文、作品标题及相关术语。图片翻译使用您当前标签页可见区域的截图、裁剪图片、识别出的原文和译文。

扩展使用当前网站域名保存站点设置。为匹配小说章节与缓存，还会在本地记录小说站点、作品与章节标识、章节网址和标题、原文与译文缓存、处理时间及相关设置。扩展不建立覆盖您全部浏览活动的历史记录。

本机用量统计包括 API 请求次数、Token 用量、缓存用量、估算费用和更新时间，用于向您展示使用情况。扩展不记录点击、按键、鼠标位置或滚动轨迹。

翻译网页邮件、聊天或其他通信时，其中的文字或图片可能发送给模型服务。整页翻译还可能处理同一页新收到的消息，具体范围见下节。扩展不连接邮箱 API，也不在后台同步邮件或消息。您翻译的内容可能含有个人或敏感信息，扩展不会按姓名、健康、支付或信用状况等类别单独建档。

何时处理内容

在普通网页上，您可以通过工具栏、快捷键、右键菜单或扩展界面启动翻译。只有使用图片翻译时，扩展才会截取当前标签页的可见区域。

整页翻译启动后，同一页面新出现的文字也可能自动发送给所选模型，例如滚动加载的段落或新收到的消息。还原页面、离开当前页面或达到追加翻译上限（每页 60,000 个字符或 1,200 个文本节点）后，这一处理停止。跳到同一页的已有锚点仍算同一页面。对于内嵌框架，只有翻译开始时已经存在且扩展能访问的文档才在此范围内。之后才加载的框架文档不参与自动翻译。

在“小説家になろう”和“カクヨム”的受支持章节页面，扩展会自动加载随包提供的脚本来识别章节。您启动整章翻译时，扩展会记录作品和章节，并可取得上下文、提取术语和缓存当前章。如果您为该站点开启下一章预翻译，扩展还可从原站读取下一章，请求模型预先翻译，并在您打开该章时应用或接续译文。已启动的后台预翻译任务可在您离开页面后继续执行。

如果您启用自动整理术语库，达到设置的章节数后，扩展会把作品标题和待整理的条目发送给您指定的翻译或润色模型。条目可能包含原文、译名、别名、分类、性别和备注。复核整理建议时，扩展还可能发送本地章节缓存中的短段原文，帮助模型判断术语在作品中的含义。

谁会收到数据

内置模型服务包括 DeepSeek、OpenAI、Anthropic、xAI 和 Google。自定义接口的接收方由您填写的地址决定。翻译和润色可以选择不同的服务商，因此相关原文、初译、上下文、提示词和术语可能发给不同的接收方。

调用模型、测试连接或获取模型列表时，扩展会按接口要求把 API 密钥作为认证信息发给所选服务商。获取模型列表也可以使用您刚输入、尚未保存的密钥，这项请求不含网页正文。扩展不会把已保存的密钥插入翻译正文或提示词。

图片翻译先在本机截图，再按图片的位置裁剪、缩放和压缩。视觉模型收到的是裁剪区域的像素，边缘可能包含相邻的网页内容。完整的标签页截图留在本机。

发送给模型 API 的请求不携带浏览器 Cookie。扩展从原小说网站读取相邻章节时，浏览器可能附带该网站已有的登录会话，以取得您有权访问的内容。扩展不通过 Cookie API 读取或导出 Cookie 值。

接收方可能获得请求内容、认证信息，以及 IP 地址、请求时间等网络信息。服务商是否保留日志、将数据用于训练或人工审核、在哪里处理及如何删除数据，取决于该服务商的政策和您的账户设置。使用自定义接口时，也请核实实际接收方的政策。

本地存储与保留

API 密钥、设置、模型列表和能力记录、术语库、作品元信息、章节缓存及用量汇总保存在本机浏览器的 chrome.storage.local 中。扩展不使用 chrome.storage.sync 同步这些数据。扩展未对 API 密钥另行加密，本地保护依赖浏览器、操作系统的访问控制和设备安全。

每部作品最多缓存 30 章，章节缓存的有效期为 30 天。扩展在读取或后续写入缓存时检查过期记录，实际清理时间可能晚于到期日。设置、术语库及作品元信息没有统一的自动到期时间。自动整理修改术语库时，扩展还会在本地保留上一次整理前的快照和整理记录，以便撤销。

完整截图、裁剪图片和图片识别结果只用于当前任务和界面展示，扩展不会将它们写入持久存储。关闭图片结果面板会清空该面板持有的结果，内存由浏览器释放。

您的控制与删除方式

您可以在设置中更换或清除已保存的 API 密钥，修改模型和提示词，关闭相应网站的功能或自动术语整理，清零用量统计，或清空指定作品和目标语言的术语库。清空该术语库也会清除对应的整理记录，章节缓存和作品元信息仍保留在本机。

您可以通过浏览器管理扩展的网站访问权限。卸载扩展会清除它在该浏览器中的本地扩展存储。

从本机清除密钥不会在服务商处撤销密钥，也无法撤回已发出的请求。如需撤销密钥、变更留存设置或删除服务商已接收的数据，请通过对应服务商办理。

传输与有限使用

内置远程端点使用 HTTPS。自定义服务商设置也允许使用 localhost 或 127.0.0.1 上的 HTTP 接口，这类本地连接不提供 TLS 传输加密。

Baka Translator 遵循 Chrome Web Store 用户数据政策及其有限使用（Limited Use）要求。通过扩展取得的信息仅用于提供或改进翻译及直接相关的功能。扩展不出售这些信息，也不将其用于定向广告、广告画像、信用评估或放贷判断。开发者不收集这些信息来训练通用人工智能模型。

向所选服务商发送执行翻译所需的数据，是您使用模型功能的一部分。第三方服务如何处理收到的数据，取决于其政策和您的账户配置。
