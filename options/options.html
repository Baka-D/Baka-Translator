      图片翻译与隐私

      • 图片翻译为实验性功能：只处理当前可见画面中的图片，识别与译文展示在页面左下角的面板中。
      • 只有在你主动触发翻译时，选中的文本、页面文本或截图才会发送给所选模型服务；本扩展不会在后台自行上传页面内容。
      • API Key 仅保存在本机扩展存储（chrome.storage.local）中，只有扩展后台在请求对应服务时使用。
      • 扩展不含统计代码、广告或第三方请求；网络请求只会发送到你配置的模型服务地址。
      • 浏览器安装时可能会请求网站访问权限，用于网页翻译和直连模型接口；翻译结果始终以纯文本写入页面，不会被当作 HTML 执行。

      站点设置

      开启后，翻译完当前章节会在后台预翻译下一章（受配额/缓存限制）；打开下一章自动应用。提示词预设可按站点覆盖：例如普通网站用常规、轻小说站点用轻小说，留空则跟随全局。站点按域名匹配，不含端口。

      还没有站点设置。弹出框中的“本站润色 / 预翻译下一章”开关会自动添加当前站点，也可以在下方手动添加。

      术语库

      同一轻小说建立术语库后，可以在这里查看和编辑。修改只保存在本机，保存后对后续发起的翻译、润色和预翻译生效；已经翻译的页面刷新或重新翻译后才会使用新术语。

      还没有术语库。同一作品完成第 3 章时会自动建立术语库；也可以先正常翻译几章再回到这里查看。
